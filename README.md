A collection of my capture-the-flag (CTF) challenge write-ups, documenting my
approach, thought process, and the things I learned along the way.

## Write-ups

**[One Diamond Short](2026/RowdyCyberCon2026/OneDiamondShort/WriteUp.md)** — Reverse Engineering (Easy)
  — Rowdy CyberCon 2026. A Minecraft demo where you need 10 diamonds to win but
  can only mine 9. Solved with static analysis (Ghidra) and live memory
  manipulation (Cheat Engine).
